## 🛒 Smart Multi-Vendor Marketplace

A full-stack e-commerce platform where customers can browse products, manage their cart and wishlist, place orders, and sellers can manage products through a dedicated Seller Dashboard.

### Key Features

- User Authentication
- JWT Authorization
- Product Catalog
- Wishlist
- Shopping Cart
- Seller Dashboard
- Product Management
- Responsive UI
- PostgreSQL Database
- REST API Architecture
